| `design-ui-finish-gate-reviewer.md` | gate kualitas UI dashboard |

| `testing-reality-checker.md` | memeriksa klaim "sudah selesai" |

| `security-secrets-credential-engineer.md` | token, cookie, `.env`, rotasi kredensial |
| `security-ai-generated-code-auditor.md` | audit kode hasil AI: secret keras, akses data longgar |
| `data-privacy-officer.md` | retensi, penghapusan data, DSAR, PII di log |

`specialized/`, atau divisi lain di repo sumber, lalu tambahkan barisnya di
tabel ini. Jangan menyalin seluruh repositori: 7,5 MB teks persona tidak
sebanding manfaatnya untuk satu proyek.
